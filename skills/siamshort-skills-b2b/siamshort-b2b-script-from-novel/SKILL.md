# Siamshort Script-from-Novel — Dynamic Visual Flow Storyboard Master

แปลง **ความคิด/การบรรยายในใจ** → **ภาพที่กล้องถ่ายได้** ทุกบรรทัด
ผลลัพธ์คือบทถ่ายทำที่ action ชัด พร้อมส่งต่อให้ทีม storyboard / Seedance / Fable หรือใช้เป็น AI comic / short-drama script

> สกิลนี้ reverse-engineer มาจากบท "กุหลาบเผาใจ ตอนที่ 2" ที่ใช้ระบบ Dynamic Visual Flow
> ดูตัวอย่างมาตรฐานทองคำเต็มๆ ได้ที่ `reference/golden-example.md` (อ่านก่อนถ้าไม่แน่ใจ output ควรหน้าตาแบบไหน)

---

## 0) กฎเหล็กข้อเดียว (The One Law)

**ทุกอย่างต้อง "มองเห็นได้" หรือ "ได้ยินได้"** — ห้ามมีประโยคบรรยายความรู้สึก/ความคิดลอยๆ ที่กล้องถ่ายไม่ได้

ทุกประโยคในต้นฉบับต้องถูกแปลงเป็น **1 ใน 4 ช่อง** เสมอ:

| ช่อง | ใช้เมื่อ | เขียนเป็น |
|---|---|---|
| **△ Action** | สิ่งที่ "เห็น" ได้ — ท่าทาง สีหน้า มือ การเคลื่อนไหว props แสง | `△ ...` |
| **(V.O.) เสียงในใจ** | ความคิด/บรรยายในใจที่ "ต้องเก็บไว้" จริงๆ (ใช้ให้น้อย เลือกเฉพาะประโยคคม) | `ชื่อ (V.O.): ...` |
| **บทพูดจริง** | สิ่งที่ตัวละคร "พูดออกมา" | `ชื่อ: (คิว) บทพูด` |
| **【音效】 เสียง** | เสียงประกอบ/SFX/เพลง | `【音效】... — ...` |

ถ้าแปลงประโยคไหนไม่ได้สัก 1 ใน 4 ช่อง → ประโยคนั้น **ตัดทิ้ง** หรือ **หาวิธีทำให้เห็นเป็นภาพ**
นี่คือสิ่งที่ทำให้ "action ชัด" — ไม่ใช่ format แต่คือวินัยข้อนี้

**ตัวอย่างการแปลง (จากของจริง):**

- ❌ นิยาย: "ความคิดวกวนที่เวียนเข้าออก ใจหนึ่งบอกให้ล้มเลิก อีกใจไม่ยอม"
  ✅ → `△ โรสรินนอนแช่นิ่ง · นิ้วเคาะขอบอ่างเป็นจังหวะช้าๆ · ขมับเต้นตุบๆ` + `โรสริน (V.O.): ...`
- ❌ นิยาย: "ร่างนางฟ้ามันได้ตายจากไปนานแล้ว" (บรรยาย)
  ✅ → `△ มองเงาตัวเองในกระจก → ยกยิ้มเย็น` + **บทพูดกระซิบ** `โรสริน: (กระซิบกับเงาตัวเอง) ร่างนางฟ้าตายไปนานแล้ว`
- ❌ นิยาย: "ทศทิศและบัวบุษบงรู้ทันกัน" (เล่าให้ฟัง)
  ✅ → `△ แววตาทศทิศกับบัวบุษบงประสานกัน — รู้ทัน` (show ผ่าน eyeline)

> **เคล็ดยกระดับ:** ประโยค climax ในใจที่ทรงพลังที่สุด ให้พยายามดันออกมาเป็น **บทพูดจริง** หรือ **action เด็ด** ก่อน เก็บ V.O. ไว้สำหรับ subtext ที่พูดออกมาไม่ได้เท่านั้น

## 1) Workflow (ทำตามลำดับนี้)

### Step 1 — ระบุโหมด
- **โหมดดัดแปลง (Adaptation):** ผู้ใช้ส่ง prose/นิยาย/บทบรรยายมาแล้ว → ไป Step 2
- **โหมดสร้างใหม่ (Creation):** มีแค่ไอเดีย/ลอจไลน์ → ถามสั้นๆ (เรื่องเกี่ยวกับอะไร, ตัวละครหลัก, โทน, กี่ตอน/กี่ฉาก) แล้วร่างโครงก่อนเข้า Step 3
- ถ้าเป็นซีรีส์หลายตอนและยังไม่มีโครง → เสนอทำ **outline ทั้งซีรีส์** ก่อน (ตัวละคร + เส้นเรื่องรวม + แบ่งตอน) แล้วค่อยลงรายตอน

### Step 2 — Fast Extraction (สกัดข้อมูล)
อ่าน prose แล้วดึง:
1. **ตัวละครที่ปรากฏในตอนนี้** + บทบาทย่อ (ทำเป็นตาราง)
2. **ฉาก/สถานที่** และ **เส้นเรื่องของตอน** (1–2 บรรทัด)
3. **รายการฉากหลัก** (Scene 1, 2, 3...) พร้อมชื่อฉากและสิ่งที่เกิดขึ้น

### Step 3 — ยืนยันกับผู้ใช้
แสดงข้อมูลที่สกัดได้ แล้วถามสั้นๆ ว่า **ถูกต้องไหม / จะปรับอะไรก่อนไหม** และถาม **ระดับความละเอียด**:
- **ละเอียดตามหนังสือ (faithful)** — เก็บทุก beat/บทพูดจากต้นฉบับ ขยายเป็น action เต็ม (ค่าเริ่มต้นเมื่อผู้ใช้ส่ง prose ที่ดีมา)
- **กระชับ (condensed)** — ตัดให้เหลือ beat สำคัญ เร่งจังหวะแบบ short-drama

> ถ้าผู้ใช้สั่งชัดว่า "ทำเลย/ละเอียดตามหนังสือ" แล้ว ข้ามการถามซ้ำ — ยืนยัน 1 ครั้งพอ อย่าถามวน

### Step 4 — แปลงเป็น Standard Format
เขียนบททีละฉาก ตาม **format spec (§2)** + **conversion engine (§0)** + **scene-craft (§3)**
แปลงทุกประโยคผ่านกฎเหล็ก ทำให้ครบทุกฉาก

### Step 5 — ส่งมอบ + QC
ตรวจตาม **checklist (§5)** ก่อนส่ง แล้วบอกผู้ใช้ว่าจะ **ส่งต่อเข้า pipeline** (storyboard/Seedance/Fable) ต่อได้ (§6)

## 2) Format Spec (โครงสร้างเป๊ะ)

### 2.1 หัวเอกสาร (ครั้งเดียวบนสุด)
```
Dynamic Visual Flow Storyboard Master
<ชื่อเรื่อง>
ตอนที่ <N>
```

### 2.2 หัวฉาก (Scene) — ขึ้นฉากใหม่
```
Scene <N> — "<ชื่อฉาก>"

出场人物： ชื่อA、ชื่อB、ชื่อC
```
- ชื่อฉากใส่ในเครื่องหมายคำพูด คั่นด้วย em-dash `—`
- `出场人物：` = "ตัวละครที่ปรากฏในฉากนี้" คั่นชื่อด้วย `、` (ลิสต์ใหม่ทุกฉาก)

### 2.3 หัวซีนย่อย (Sub-scene) — เปลี่ยนสถานที่/เวลา/มุม
```
<ตอน>-<ลำดับ> <สถานที่> 【内】 [เวลา]
```
- เช่น `2-1 ห้องน้ำในบ้านวโรวงศ์ 【内】 [เช้า]`
- `【内】` = ภายใน(INT) · `【外】` = ภายนอก(EXT)
- `[เวลา]` ภาษาไทย: `[เช้า] [สาย] [กลางวัน] [เย็น] [กลางคืน]`
- 1 ฉากใหญ่ แตกได้หลายซีนย่อย (เปลี่ยนห้อง/เวลา = ซีนย่อยใหม่)

### 2.4 บรรทัดเนื้อหา
```
△ <action ที่กล้องถ่ายได้ — 1 beat ต่อ 1 บรรทัด>

ชื่อ: (คิวอารมณ์/บล็อกกิ้ง) บทพูด

ชื่อ (V.O.): เสียงในใจ

ชื่อ (O.S.): บทพูดนอกเฟรม / จากหลังประตู

【音效】<คำบรรยายเสียง> — <onomatopoeia/คุณภาพเสียง>
```
**กฎการเขียน:**
- ทุก action ขึ้นต้น `△ ` เสมอ — 1 beat ต่อบรรทัด (อย่ายัดหลาย action รวดเดียว) ถ้าอยากต่อ micro-beat ในบรรทัดเดียวใช้ `·` คั่น
- ใช้ `—` (em-dash) นำ "ผลลัพธ์/การเปลี่ยน" ของ beat เช่น `△ เธอลืมตา — แววตาเปลี่ยน เย็นชา`
- บทพูด: ใส่คิวในวงเล็บก่อนข้อความเสมอเมื่อมีอารมณ์/ท่าทาง: `โรสริน: (ยิ้มเย้ย) ...`
- **เว้นบรรทัดว่าง 1 บรรทัดระหว่างทุก element** (อ่านง่าย ตัด beat ชัด)
- 1 บทพูดยาวไม่เกิน ~50 คำ ถ้ายาวให้ซอยเป็นหลายบรรทัด คั่นด้วย action

### 2.5 ปิดฉาก/ปิดตอน
```
【音效】<เสียง/เพลง> — fade out

FADE OUT


— จบตอนที่ <N> —

[ติดตามตอนต่อไป]
```

> หมายเหตุ label: format ต้นฉบับใช้ token จีน (`出场人物` `内` `外` `音效`) ปนไทย — เก็บไว้แบบนี้เป็นค่าเริ่มต้นเพราะคือสิ่งที่ผู้ใช้ชอบ ถ้าผู้ใช้อยากได้ไทยล้วน ค่อยสลับเป็น `ตัวละคร：` `[ใน] [นอก]` `【เสียง】`

## 3) Scene-Craft (จังหวะหนัง — ทำให้บท "มีพลัง")

1. **เปิดฉากด้วยภาพแรง (Strong Open):** ซีนย่อยทุกซีนเปิดด้วย △ ภาพที่ตั้งอารมณ์ทันที
   _เช่น: ไอน้ำเหนืออ่างหินอ่อน / เข็มนาฬิกาชี้ 7 โมงครึ่ง / ประตูลิฟต์เปิด_
2. **ปิดฉากด้วย hook:** ทุกฉากจบบนความตึง/คำถาม/ภาพค้าง
   _เช่น: "เธอวางช้อนลงช้าๆ" หลังสบตา / ส้นสูงกระทบพื้น กึก กึก กึก / "เธอรู้ตัว — อยู่ในห้องเขาลำพัง"_
3. **แตก beat ถี่:** หนึ่งความรู้สึกใหญ่ = หลาย △ สั้นๆ ไล่กัน (นิ่ง → นิ้วเคาะ → ขมับเต้น → หลับตา → ลืมตา แววตาเปลี่ยน) อย่ารวบเป็นก้อนเดียว
4. **Beat-timing แทรกความเงียบ:** ใส่จังหวะหยุดเป็น action — `△ อากาศเงียบลงสามวินาที` / `△ สามวินาทีผ่านไป`
5. **Subtext = eyeline:** ความสัมพันธ์/การรู้ทันกัน เล่าผ่าน △ สบตา ไม่ใช่บรรยาย — `△ แววตาสองคนประสานกัน — รู้ทัน`
6. **Reaction ordering:** วาง action เหตุ→ผลให้กล้องตัดได้ — `△ เขายิ้ม` ก่อน `△ เธอชะงักเมื่อเห็นรอยยิ้มนั้น`
7. **【音效】 ตอกอารมณ์:** ใส่เสียงจริง (เครื่องถ่ายเอกสาร, เคาะประตู ก๊อกๆ, ส้นสูง) + เพลงตึงตอนปิดฉาก

## 4) เทคนิคยกระดับ (Elevation — สิ่งที่ทำให้ "ชอบมากๆ")

- **Externalize อารมณ์เป็น micro-action:** กำช้อนแน่น / ผ้าเช็ดปากยับใต้โต๊ะ / ข้อนิ้วขาว / ย่นจมูก (callback วัยเด็ก) / ขมับเต้น
- **Props ที่มีความหมาย:** ร่องรอยจางๆ ของแหวนแต่งงาน → ถูกจูบที่รอยแหวน — ของชิ้นเดียวเล่าทั้ง backstory
- **Sensory specificity:** อย่าเขียน "รองเท้า" เขียน "ส้นสูงสีดำพื้นแดง"; อย่าเขียน "เสื้อคลุม" เขียน "เสื้อคลุมผ้าไหมสีแดงเลือดหมู" — รายละเอียดจำเพาะ = ภาพคม
- **Callback ทางกาย:** ท่าทางเดิมจากอดีต (ย่นจมูกใส่หลังเขา "เหมือนตอนเด็ก") สร้าง depth โดยไม่ต้องอธิบาย
- **เปลี่ยน narration ปิด beat เป็นบทพูด:** ประโยคสรุปในใจที่เท่ที่สุด ลองให้ตัวละครพูด/กระซิบออกมา
- **แปลง "ผู้บรรยายรู้ทุกอย่าง" เป็น POV ภาพ:** สิ่งที่ผู้บรรยายเล่า ให้เปลี่ยนเป็นสิ่งที่ "ตัวละครเห็น/ทำ" ในเฟรม
- **เก็บรสภาษาต้นฉบับ:** สำนวน/มุก/บทพูดเด็ดของผู้เขียนเดิม (เช่น "เหนือฟ้ายังมีฟ้า เหนือโรสรินยังมีรุจิรา") เก็บไว้ — แปลงเป็น V.O. หรือ action ได้ แต่อย่าทิ้งเสน่ห์

## 5) QC Checklist (ตรวจก่อนส่ง)

- [ ] ไม่มีประโยคบรรยายความรู้สึก/ความคิดที่กล้องถ่ายไม่ได้หลงเหลือ (ทุกอย่างเข้า 1 ใน 4 ช่อง)
- [ ] ทุก action ขึ้นต้น `△` · 1 beat ต่อบรรทัด · เว้นบรรทัดว่างครบ
- [ ] ทุกฉากมี `出场人物：` · ทุกซีนย่อยมี `【内/外】 [เวลา]`
- [ ] บทพูดมีคิวอารมณ์ในวงเล็บเมื่อจำเป็น · ไม่มีบทพูดยาวเกิน ~50 คำ
- [ ] ทุกซีนเปิดด้วยภาพแรง · ทุกฉากปิดด้วย hook
- [ ] มี 【音效】 อย่างน้อยจุดสำคัญ · ปิดตอนด้วย FADE OUT + การ์ดจบตอน
- [ ] V.O. ใช้เท่าที่จำเป็น (ไม่ท่วม) · subtext เล่าผ่าน eyeline/action
- [ ] รักษาบทพูด/มุก/รายละเอียดเด่นจากต้นฉบับ (โหมด faithful)
- [ ] ชื่อตัวละครสะกดตรงกันทั้งบท

## 6) Handoff เข้า pipeline ของ pton

บทจากสกิลนี้คือ **input ตัวอักษร** ไม่ใช่ปลายทาง — เสนอผู้ใช้ต่อยอด:
- `/storyboard` → เปลี่ยนแต่ละ △/ซีนเป็น panel storyboard sheet (GPT Images 2.0) ใช้เป็น ref
- `/seedance-shot-continuity` หรือ `/fable-auto-director` → gen วิดีโอทีละช็อตจากบทนี้ (1 ซีนย่อย ≈ 1 ช็อต 15 วิ)
- เตือนข้อจำกัด Seedance: **ตัวหนังสือบนภาพต้องเป็นอังกฤษ** (บทพูดไทยพากย์ได้ แต่ comic SFX/overlay ต้อง EN)
- ของเด่น/props สำคัญ (เช่น แหวน) ควรทำเป็น virtual asset ใน Fable เผื่ออ้างอิงตอน gen

> ถ้าผู้ใช้จะ gen เป็นวิดีโอจริง: 1 ซีนย่อย map ≈ 1 ช็อต, แต่ละ △ คือ beat ภายในช็อต — ออกแบบให้ช็อตจบแบบ handoff สู่ช็อตถัดไป (ดู memory `seedance-shot-ending-handoff`)

## 7) สรุปสั้นสำหรับเริ่มงานเร็ว

1. มี prose → สกัด (ตัวละคร/ฉาก/เส้นเรื่อง) → ยืนยัน 1 ครั้ง + ถามระดับละเอียด
2. แปลงทุกประโยคผ่าน **กฎเหล็ก 4 ช่อง** (§0)
3. จัดตาม **format spec** (§2): Scene → 出场人物 → ซีนย่อย 【内/外】[เวลา] → △/บทพูด/V.O./音效
4. ใส่ **scene-craft** (เปิดแรง/ปิด hook/แตก beat/eyeline) + **เทคนิคยกระดับ**
5. ตรวจ **checklist** → ส่ง → เสนอ handoff เข้า pipeline
