## ⭐ 1) SCENE DESIGN = มุมกว้างเห็นทั้งห้องในเฟรมเดียว (eye-level wide) + ANCHOR ทุกโซนไม่ซ้ำ  (เทคนิคหลัก/ใหม่สุด)

**ปัญหา:** ฉากหรู/สมมาตร (เช่น บันไดสองด้านเหมือนกัน, มุมห้องซ้ำๆ) → AI ไม่มีทางรู้ว่าตัวละครอยู่โซนไหน → **slop / ตำแหน่งพลิกสลับ**

**หลักการแก้:**
1. **วางผัง geography ของห้องให้ชัด (อะไรอยู่โซนไหน) — ❌ ไม่จำเป็นต้องมุมสูง/top-down** ⭐ รูป scene ref ที่ใช้จริง = **"มุมกว้างระดับสายตา (eye-level wide establishing) เห็นทุกโซนในเฟรมเดียว"** (ตามรูปตัวอย่าง 4 ห้องในข้อ 6) ไม่ใช่ bird's-eye. จะร่าง top-down ในหัวเพื่อช่วยล็อกผังก็ได้ แต่นั่นเป็นแค่ blueprint ความคิด ❌ ไม่ใช่ format ของรูป ref — เพราะวิดีโอ Seedance ถ่าย eye-level ดังนั้น scene ref ควร **match มุมที่กล้องจะเห็นจริง** (มุมกว้างระดับสายตา) ไม่ใช่ภาพ map มองจากเพดาน
2. **ทำลายความสมมาตร — ทุกโซนต้องมี "landmark เด่นไม่ซ้ำกัน" เป็น anchor**
   - แม้แต่ของที่ปกติเหมือนกัน (บันไดซ้าย/ขวา) ต้องวางของต่างกันเพื่อแยก
   - ตัวอย่าง (คฤหาสน์กุหลาบ):
     - บันไดซ้าย = พรมแดง + **นาฬิกาตั้งพื้นโบราณ** + ผนังแขวน**รูปพ่อ(กรอบทอง)**
     - บันไดขวา = บันไดไม้เปลือย(ไม่มีพรม) + **ต้นปาล์มกระถางน้ำเงิน** + **รูปปั้นหินอ่อนผู้หญิง**
     - มุมขวาหน้า = **เปียโนแกรนด์สีดำ** ; มุมซ้ายหน้า = โต๊ะคอนโซล+ตู้โชว์รูปครอบครัว
     - กลางห้อง = โซฟาตัวยู + โต๊ะกลาง**แจกันกุหลาบแดง**+รูปครอบครัว
3. **ระบุตำแหน่งแบบ ABSOLUTE (อ้าง landmark ตายตัว) ❌ ไม่ใช่ ซ้าย/ขวา/บน ตามมุมกล้อง**
   - ❌ "ซ้าย/ขวา" = พลิกตามทิศกล้อง → slop
   - ✅ "ข้างนาฬิกาโบราณ / ฝั่งเปียโน / ตีนบันไดขวา" = ตายตัวทุกมุมกล้อง
   - **กลุ่มของที่ซ้ำ (เช่นโซฟา 3 ตัว) ก็อ้างกับ landmark ข้างเคียง:** โซฟาฝั่งนาฬิกา / โซฟาฝั่งเปียโน / โซฟาตัวยาวฝั่งบันได (ไม่เรียกซ้าย/ขวา)

**ตัวอย่างคำสั่งที่ไม่มีวันสับสน:**
> "โรสนั่งโซฟา**ฝั่งเปียโน** หันหน้าหาป้าจวงที่ยืน**ข้างนาฬิกาโบราณตีนบันไดซ้าย**" — กล้องถ่ายมุมไหนก็ตำแหน่งเดิม

4. **อ้างเฉพาะ "ของจริงที่มีในรูป ref" + ล็อกห้ามมโน** ⚠️ (บทเรียนจากเทสจริง)
   - ถ้าอ้างของที่ "ไม่มีจริงในรูป" (เช่นสั่ง "โรสนั่งโซฟาฝั่งเปียโน" แต่รูปมีโซฟายูอยู่กลางห้อง เปียโนแยกขวา ไม่มีโซฟาติดเปียโน) → AI จะ **มโนเฟอร์นิเจอร์ใหม่ขึ้นมาเอง** (โต๊ะ/โซฟา/แจกัน) = drift
   - แก้: (ก) อ้างของที่ "มีจริง" เช่น "โซฟายูกลางห้อง ตัวฝั่งใกล้เปียโน" + ใช้เปียโนเป็น **bg** (ไม่ใช่เป็นที่นั่ง) (ข) ใส่ล็อก `❗ใช้เฉพาะเฟอร์นิเจอร์ที่มีในรูป &ref ; ❌ห้ามเพิ่มโต๊ะ/เก้าอี้/โซฟา/แจกันที่ไม่มีในรูป` (ค) **verify ไขว้หลาย agent** — AI ชอบแอบเพิ่ม prop เล็กๆ (เช่นแจกันลายคราม) ต้องจับให้เจอ

5. **ช็อต WIDE เห็นผนังหลัง = ตัวกระตุ้นให้ AI สร้างสมมาตร/ของซ้ำ** ⚠️ (บทเรียน sb3 กุหลาบ — workflow จับได้ ตาเปล่ามองข้าม)
   - เคสจริง: ช็อต wide เห็นผนังหลัง → Seedance **mirror เปียโน(ขวา)ไปซ้าย เป็น 2 ตัวขนาบรูปปั้นกลาง** + งอกโคมไฟตั้งโต๊ะ + ทำแถบกระจกสะท้อน/ห้องซ้อน (โคลนคนตัวเล็กในแถบ) = ทำลายผังอสมมาตรที่ตั้งใจ + บันได/นาฬิกาซ้ายหายไป
   - แก้: (ก) **เลี่ยง WIDE ที่เห็นผนังหลังเต็มห้อง** ใช้ medium/MCU ปักตัวละครกับ landmark ฝั่งเดียว (ไม่เห็นทั้ง 2 ฝั่งพร้อมกันในเฟรมเดียว) (ข) ใส่บล็อก `⛔ LAYOUT LOCK (อสมมาตร ห้าม mirror)` ระบุของที่มี **"ตัวเดียว/ฝั่งเดียว" ให้ชัด** เช่น "เปียโนตัวเดียวฝั่งขวา ; ฝั่งซ้าย=บันได+นาฬิกา ไม่ใช่เปียโน" + `❌ห้าม mirror ซ้าย-ขวาให้สมมาตร ❌ห้ามของตัวที่สอง ❌ห้ามโคมไฟงอก ❌ห้ามกระจกสะท้อน/ภาพห้องซ้อน` (ค) verify ไขว้จับเปียโน/โคมไฟ/แถบ mirror ทุกครั้ง
   - 📌 **แยกให้ออก: "ช็อตวิดีโอ WIDE เห็นผนังหลังเต็ม (อันตราย)" ≠ "scene ref มุมกว้างเห็นทุกโซน (ที่เราต้องการ)".** scene ref มุมกว้างเป็น *รูปฉากนิ่งไม่มีคน* ที่จงใจให้ landmark อสมมาตรครบทุกโซน (ดีต่อการล็อกผัง — ดูข้อ 6) ; ส่วนข้อห้ามนี้คือ *ช็อตวิดีโอ* wide ที่เอาตัวละครไปยืนกลางห้องเห็นผนังหลังสองฝั่งพร้อมกัน (Seedance ชอบ mirror) — ตอน gen **วิดีโอ** จึงค่อยปักตัวกับ landmark ฝั่งเดียวด้วย medium/MCU

6. **⚠️ scene ref ต้องเป็น "มุมกว้างระดับสายตา เฟรมเดียว (eye-level WIDE establishing)" ที่เห็นทุกโซน + anchor อสมมาตรในภาพเดียว (4 มุม/โซนต่างกันชัด)** — ❌ ไม่ใช่ 3x3 turnaround/contact sheet/กริด (กริดทำ AI งง + เสี่ยง Seedance ลอก layout เป็น split) และ ❌ ไม่ต้อง top-down/bird's-eye. ⚠️ **บทเรียนเครื่องมือ (กุหลาบ EP3):** `regen_scene_image` **ดีฟอลต์ auto-build เป็น "3x3 scene turnaround sheet" 9 มุม** ถ้าไม่ส่ง `prompt` → **ต้องส่ง `prompt` custom เองทุกครั้ง** สั่ง "single eye-level WIDE establishing, ONE continuous frame, ❌NOT grid/turnaround/contact sheet/split, ❌NOT top-down/overhead" + ลิสต์ anchor รายโซน (กลาง/ผนังหลัง/ซ้าย/ขวา/หน้า) ให้ของแต่ละโซนต่างกัน + lighting ตามเวลา.
   - **ฟอร์แมตที่ถูก = wide eye-level เดี่ยว เห็นทุกโซนในภาพเดียว** — เทียบรูปตัวอย่าง 4 ห้อง (p'ton คอนเฟิม 2026-06-27):
     - 🛁 **ห้องน้ำหรู** : กระจก+อ่างล้างหน้า(ซ้าย) · อ่างอาบน้ำ+หน้าต่างฝ้า(กลาง) · ตู้อาบน้ำกระจก+เสื้อคลุม+ต้นไม้(ขวา)
     - 🍽 **ห้องอาหาร** : ตู้ไม้+ชุดน้ำชาเงิน(ซ้าย) · โต๊ะยาว+โคมระย้าคริสตัล+หน้าต่างม่านขาว(กลาง) · นาฬิกาแขวน+ตู้กระเบื้องลายคราม(ขวา)
     - 🛋 **ห้องทำงาน/โซฟา** : โซฟาหนัง+ชั้นหนังสือ(ซ้าย) · โต๊ะทำงาน+วิวเมืองกระจกเต็มบาน(กลาง) · บาร์+ตู้ไวน์+แจกัน(ขวา)
     - 🏢 **ห้องเลขา** : เครื่องถ่ายเอกสาร+ล็อกเกอร์(ซ้าย) · โต๊ะเลขา+โซฟา+หน้าต่างเมือง(กลาง) · ประตูไม้ป้าย "PRESIDENT"(ขวา)
     - → ทุกใบ = **มุมกว้างระดับสายตา ภาพเดียว เห็นซ้าย-กลาง-ขวาครบ แต่ละโซน landmark ไม่ซ้ำ** (นี่คือเป้าหมายของ scene ref)

**ลำดับการทำ:** วางผัง geography (โซน+anchor อสมมาตร — ในหัว/ร่าง ไม่ต้อง top-down) → gen รูป scene ref **มุมกว้างระดับสายตา เฟรมเดียว (eye-level wide establishing)** (custom prompt ห้ามกริด/ห้าม bird's-eye ; มี landmark/เฟอร์นิเจอร์จริงโผล่ชัด อสมมาตร เห็นทุกโซนในภาพเดียว) → วาง blocking ตัวละครตามพิกัด landmark โดยอ้างเฉพาะของจริง

## 2) CAM/BG LOCK — ปัก "ทิศกล้อง + ฉากหลังรายตัว" ทุกคัท

ทุกช็อต/ทุกคัทระบุ: (1) กล้องหันทางไหน (2) **หลังตัวละครแต่ละคนเห็น landmark อะไร** เช่น `@วิน หลัง=แท่นบูชา/เปียโน`, `@โรส หลัง=บันไดซ้าย/นาฬิกา`
- **เหตุผล:** ถ้าไม่ปัก BG, Seedance จะดูดตัวละครไปหา anchor ที่เด่นสุด → ย้ายจุด/กลับด้าน (เคสจริง: แม่เด้งไปหน้าหีบศพ, วินอยู่คนละจุดระหว่าง 2 ช็อต)
- ช็อตคู่เดิมต่อเนื่อง → สั่ง "ฉากหลังเหมือนช็อตก่อนเป๊ะ" เพื่อล็อกมุมให้ตรงกัน
- ⛔ **POSITION LOCK ข้ามทั้งฉาก = ปัก "ฝั่ง + BG anchor ตายตัวให้แต่ละตัวละคร" แล้วใช้ซ้ำทุกช็อต ห้ามสลับด้าน** (คำสั่ง pton: *"ตำแหน่งต้อง lock ไว้ อย่าให้พลาด slop ย้ายตำแหน่งตัวละครเด็ดขาด"*)
  - เคสจริง (กุหลาบ ตอน1): โรส=ฝั่งประตู (BG ประตู+สวน golden hour) คงที่ทั้งฉาก / ป้าจวง=ฝั่งบันได (BG บันได+นาฬิกา) คงที่ — ทุกช็อต reverse กันบนเส้น 180° เดิม ไม่มีใครข้ามฝั่ง
  - เขียนล็อกตรงๆ ในบล็อก `⛔ POSITION LOCK`: ระบุ "ใครอยู่ฝั่งไหน + BG หลังเห็นอะไร + หันหน้าไปทางไหน" + `❌ห้ามสลับ Aไปฝั่งของ B / Bไปฝั่งของ A`
  - ⚠️ prompt ที่ generate ไว้ล่วงหน้าหลายช็อตมักให้ทุกคน "กลางโถง หลัง=บันได" เหมือนกันหมด = ขัดผังที่ล็อก → **ต้องไล่แก้ทีละช็อตให้ตรง anchor ก่อน gen ทุกช็อต**

## 3) SCENE REF สำหรับวิดีโอ = mention scene (#/&) + TEXT สั้น (อย่าบรรยายฉากยาว)

- `regen_shot_video` **ไม่แนบรูปฉากจาก sceneIds เฉยๆ** → ต้อง **mention scene ใน prompt**: `#ชื่อScene` (scene tag) หรือ `&ชื่อVA` (virtual asset)
  - ✅ **ทดสอบแล้ว ทั้ง `#` และ `&` ดึงรูปฉากติดเหมือนกัน** (pton ชอบ `#` มากกว่า) — ตั้งชื่อ scene ให้ tag-friendly (ไม่มีเว้นวรรค/วงเล็บ) เพื่อใช้ `#` ได้ เช่น `#คฤหาสน์_กุหลาบ` ; ใช้ `update_scene` เปลี่ยนชื่อ
- **ห้ามบรรยายฉากยาวเป็นตัวอักษร** (เพดาน/เสา/ของแต่ง) เพราะ AI จะ "มโนฉากใหม่ตามคำ" → ผิดจากรูป ref
- สูตร: `Location: ใช้ฉากเดิมตามรูป #ชื่อScene เป๊ะ (เวลา/แสง) — ❗ห้ามเปลี่ยน/สร้างใหม่/แต่งเพิ่ม. Use SAME location as #ชื่อScene.`
- ถ้าใช้ `&VA`: ต้อง `byteplusSyncStatus: ready` (list_virtual_assets ; ถ้าไม่ → sync_virtual_asset_byteplus). รูป ref 2 พาเนล/หลายมุมใช้ได้ ถ้าคุม anti-split

## 5) SHOT CONSTRUCTION + ANTI-SLOP GUARDS (ใส่ทุก prompt)

- ⭐ **เปิดทุกซีน/สถานที่ใหม่ด้วย ESTABLISHING SHOT ก่อนเสมอ** (หลัก pton) — ช็อตแรกของแต่ละ location = EXT/WIDE ตัวสถานที่ (ไม่มีคน/ไม่มีบทพูด กล้องนิ่ง) บอก "ที่ไหน+เวลาไหน" แล้วค่อยตัดเข้าเหตุการณ์/บท. เช่น เข้าออฟฟิศ→ช็อตตึกใหญ่ก่อน, เข้าบ้าน→ช็อตหน้าบ้านก่อน. วิธีทำ: สร้าง scene EXT แยก (timeOfDay ให้ตรง) + แทรก storybox establishing หัวซีน (ใช้ sortOrder เศษ เช่น 0.5/7.5 ไม่ต้องรีนัมเบอร์). ถ้าหลายซีนอยู่ตึก/บ้านเดียวกัน establish ครั้งเดียวพอ + ใช้ช็อตคนเดินเข้าห้องเป็น transition.
- เปิด 0s ด้วยช็อตใกล้ๆ → ตัดฉับ hard cut สลับ MEDIUM ↔ MCU ↔ OTS (ไม่แพนเวียน)
- **กล้องระดับสายตา (eye-level)** — ❌ ห้ามมุมสูง/overhead/crane/CCTV ในวิดีโอ (ทำ Seedance เพี้ยน). มุมเท่ๆ เก็บไว้เฉพาะ reveal/ไคลแม็กซ์ และคุมไม่สุดขั้ว
- **[ANTI-CLONE]** นับตัวละครเป๊ะ "EXACTLY N" + ถ้ามีคนยืนเด่นคนเดียว ย้ำ "ยืนคนเดียว=X ที่เหลือนั่ง"
- **[ANTI-SPLIT]** ภาพเดียวต่อเนื่อง ❌ ห้ามแบ่งจอ/สองท่อน/two-panel/split/grid แม้ช็อต wide
- **ระยะไกลสองฝั่ง** → ใช้ OTS deep-focus เฟรมเดียว (ไหล่คนหน้า → อีกคนเล็กท้าย) อย่าใช้ wide "โชว์สองปลายพร้อมกัน" (จะแตก)
- พระเอก/ตัวหลัก: คุมสีหน้าตามคาแรกเตอร์ (เช่น พระเอกนิ่งขรึมสง่า ไม่ใช่หน้าคับแค้น)

## 9) CONTINUITY & ADVANCED BLOCKING (บทเรียน chapter "กลับมาเพื่อทวงคืน" 2026-06-22)

### 9.1 เปิดช็อตด้วย CLOSE-UP ให้ "ต่อเนื่องอารมณ์" จากช็อตก่อน
- ถ้าช็อตใหม่ = บทพูด/อารมณ์ "ต่อเนื่อง" ของตัวเดิม → **เปิดด้วย CLOSE-UP หน้าตัวนั้น** (ขยี้อารมณ์ + ตรึงตัวละครจุดเดิม = ฉากต่อเนื่องเนียน) แล้วค่อยตัดขยายเป็น MCU/insert
- ก่อนเขียน ให้ **วิเคราะห์เฟรมช็อตก่อน** (ชุด/ผม/ปาก/ต่างหู/ฝั่ง/bg) แล้วระบุซ้ำใน prompt + ใส่บรรทัด `🔗 ต่อเนื่องจาก sbX`

### 9.2 ใช้ "เฟรมช็อตก่อน" เป็น reference มุมกล้อง (image-to-video / %ref)
- จับเฟรมที่ชอบ: ใช้ `lastFrameUrl` ของช็อต → `upload_image(sourceUrl=...)` ได้ URL ถาวร → ตั้งเป็น `storyboardUrl` (update_shot) **และ/หรือ** `add_ref_asset_to_shot` แล้วอ้าง `%ชื่อ` ใน prompt (ตั้ง storyboardUrl จะ auto-register ref ชื่อ `image-<ts>` ให้ด้วย)
- ✅ **วิธีหลัก (official workflow) = `capture_video_frame` จับเฟรมไหนก็ได้ (`timeSec` 0~15 หรือ -1 = เฟรมสุดท้าย) → (option ⭐) `edit_reference_asset` เอารูปไปแต่งด้วย XSkill GPT-Image-2-Edit ก่อน (ลบ/เปลี่ยน bg, แก้แสง/สี/mood, เพิ่ม-ลบ element ; มี `ratio` 1:1…9:16, วิดีโอ Loop ใส่ 9:16) → `add_ref_asset_to_shot` → อ้าง `%name` ใน prompt ; หรือ `trim_reference_video` ตัดคลิป 1–15s เป็น *motion* ref. ดูเต็ม (ทุก param + error + flow) ที่ `02_REFERENCE-ASSETS_capture-edit-trim.md`.** Reference Asset เก็บ **ระดับ Chapter** สร้างครั้งเดียวใช้ได้ทุก storybox. ⚠️ ใน prompt ใช้ `%name` เท่านั้น ❌ห้าม `%uid`. ⚠️ ถ้า `capture_video_frame` พลาด (timeSec เกิน duration) → ลดเลข/ใช้ -1 ; **fallback** เดิม = `lastFrameUrl`+`upload_image` (URL ถาวร, ตั้ง `storyboardUrl` หรือ `add_ref_asset_to_shot`)
- ⚠️ **regen_shot_video คอนดิชันบน ref แบบ "ใกล้เคียง" ไม่ pin pixel เป๊ะ** → คันโยกคือ prompt: สั่ง "ใช้ %image เป็น **มุมกล้องเท่านั้น ❌ห้ามใช้ graphic style/แสงของรูปนั้น**" + ล็อกกรอบ (medium/ครึ่งตัว, กล้องไม่ถอย) ไม่งั้นมันถอยเป็น full-body / เปลี่ยน detail / เพิ่ม action เอง
- สั่ง action ให้ "ธรรมชาติ เร็ว ไม่อืด" (เช่น "ป้าโผเข้ากอดทันที" ไม่ใช่สโลว์) — Seedance ชอบทำช้า/ฝืนถ้าไม่กำชับ

### 9.3 ตัวละครเดิน + ล็อกอีกตัวให้นิ่ง (motivated follow)
- ตัวนำเดิน (โรสเดินจากประตู→โซฟากลางโถง พูดไปเดินไป) → **กล้องตามนุ่มนวล eye-level ¾ มุม** (ไม่กระตุก ไม่เวียนหัว) สื่อ "ครอบครองพื้นที่"
- ⛔ ตัวอยู่กับที่ต้องล็อกชัด **"ยืนนิ่งจุดเดิม ❌ไม่เดินตาม ❌ไม่ย้ายตำแหน่ง"** ไม่งั้น Seedance ดูดให้เดินตาม/วาร์ป
- จบช็อตเดินที่ landmark (โซฟา) เพื่อ **ส่งต่อช็อตถัดไป** ; eyeline ช็อตถัดไปอ้าง landmark ตัวนิ่ง (โรสที่โซฟา "มองไปทางฝั่งบันได"=ป้า)

### 9.4 ANTI-ARTIFACT (ใส่ทุก prompt ที่มีแสง god-ray / โคมระย้า)
- เคสจริง sb9: god-ray+โคมระย้า → เรนเดอร์ **"จานลอย/วงรีลอยกลางอากาศหลังหัว" + ผนังเหลวบิด** → ล็อก `❌ห้ามวัตถุ/จาน/โคมลอยกลางอากาศหลังศีรษะ ❌ห้ามโคมระย้าเพี้ยนเป็นจานบิน ❌ห้ามผนัง/เพดานเหลวบิด ; ฉากหลังคมชัดเป็นสถาปัตยกรรมจริง`

### 9.5 INSERT / PROP = "ของในกรอบ/ของจริง" ไม่ใช่คนจริง + กัน prop morph
- insert รูปถ่าย/ภาพในกรอบ ($รูปครอบครัว) → ย้ำ "**เป็นรูปถ่ายในกรอบเท่านั้น ไม่ใช่คนจริงยืนในฉาก**" ไม่งั้นอาจเรนเดอร์คนในรูปเป็นคนจริงเต็มตัว
- ⚠️ ของที่ตัวละคร **ถือ+ขยับ** (เช่นหยิบกรอบรูปขึ้นมามอง) เสี่ยง **morph เป็นวัตถุอื่น** — เคสจริง sb10: กรอบรูปถูกถือเอียง/แนวนอน เห็นแค่ขอบเงินบาง → เรนเดอร์เป็น "แท่ง/ขลุ่ยเงิน" → ล็อก `ถือกรอบ**ตั้งตรง หันด้านรูป/หน้าของเข้าหากล้อง เห็นชัดตลอด** ❌ห้าม morph เป็นแท่ง/ขลุ่ย/วัตถุยาว ❌ห้ามถือเอียงจนเห็นแค่ขอบ`

### 9.6 OTS sliver ≠ clone
- ช็อต reverse คนเดียว มี "ไหล่/หลังอีกตัวจริง" เบลอ foreground = OTS ปกติ (สวย+depth) ไม่ใช่โคลน — verify agent อาจ flag ผิด ให้เช็กว่าเป็นตัวจริงอีกคนหรือร่างซ้ำ

### 9.7 จบช็อตที่ "ตัวละครอยู่กับที่" = CUT ไปตัวนั้น SOLO (ไม่งั้นดริฟต์)
- อยากจบช็อตด้วยตัวที่ยืนนิ่ง (เช่น sb10 จบที่ป้ายืนตำแหน่ง sb9) → **ทำเป็น hard cut ไป "ตัวนั้นคนเดียวในเฟรม (solo, ❌ไม่มีตัวนำในเฟรม)"** ที่ landmark เดิม ; ถ้าปล่อยให้อยู่เฟรมเดียวกับตัวนำ Seedance จะ **ดูดให้เดินมายืนข้างตัวนำ (two-shot ดริฟต์)** — เคสจริง sb10 v3: ป้าเดินมาข้างโรสแทนยืนตีนบันได ; แก้ด้วย "คัทท้าย = ป้า solo + ❌ห้าม two-shot ❌ห้ามเดินเข้าหาตัวนำ" + อ้างเฟรมช็อตอ้างอิง (sb9) ให้ตรง
