# Physics Recipes — ตารางลูกโซ่ฟิสิกส์ต่อเหตุการณ์ + GOLDEN EXAMPLE

> ใช้คู่กับ `SKILL.md` (physics-guide). เลือกแถวตามชั้น 1 OBJECT AUDIT แล้วเขียนลูกโซ่ตามคอลัมน์.
> ทุก recipe จบด้วย "มรดก continuity" = สิ่งที่ต้องอยู่ต่อในช็อตถัดไป.

## §1 ของแตก/ตก (วัสดุ × พื้น)

| วัตถุ | กระเบื้อง/ปูน/หินอ่อน | พื้นไม้ | พรม/เบาะ |
|-------|----------------------|---------|-----------|
| **แก้วใสบาง (มีน้ำ)** | แตกกระจาย ชิ้นใหญ่ 3–5 + สะเก็ดละเอียดรัศมี ~50cm, เสียง "เพล้ง" คมสั้นครั้งเดียว | อาจแตก 2–3 ชิ้น หรือร้าวทั้งใบ เสียงทึบกว่า | **ไม่แตก** กลิ้งครึ่งรอบ น้ำซึมเป็นวงเข้มบนพรม |
| **แก้ว/ถ้วยเซรามิกมีหู** | หูหักหลุดแยก + ตัวแตกชิ้นใหญ่ 3–4, เศษหมุนกริ๊งก่อนนิ่ง | แตกหยาบ 2–3 ชิ้น หรือบิ่นก้น | ไม่แตก ตกตะแคง ของข้างในเทออก |
| **จานเซรามิก** | แตกผ่ากลาง + ขอบบิ่นกระเด็น, เศษโค้งหมุนติ้วก่อนหยุด (เสียงหมุนวืดๆ เป็น beat เด็ด) | ร้าว/แตก 2 ชิ้นใหญ่ | ไม่แตก คว่ำ อาหารกระจายเป็นกอง |
| **ขวด/แก้วพลาสติก** | **ไม่แตก** — เด้ง 1–2 ครั้งเสียงทึบกลวง "ป๊อก-ป๊อก" กลิ้งโค้ง ฝาอาจหลุด น้ำพุ่งเป็นจังหวะตามการเด้ง | เหมือนกัน เสียงทุ้มขึ้น | เด้งเบา กลิ้งสั้น |
| **ขวดแก้ว/ขวดไวน์** | ก้นหนามักรอด — แตกเฉพาะคอ หรือแตกทั้งใบถ้าลงมุม, ของเหลว "ทะลัก" เป็นก้อนแล้วค่อยไหล | มักไม่แตก กลิ้งเสียงหนักกึกๆ | ไม่แตก |
| **มือถือ** | คว่ำหน้าลงเสมอ (กฎเมอร์ฟี) เสียง "แปะ" ทึบแน่น — beat: ทุกคนหน้าเสียว ค้าง ก่อนกล้าพลิกดูจอ | เสียงทุ้ม เด้งเล็กน้อย | เงียบ ปลอดภัย (anticlimax ใช้เป็นมุกได้) |
| **กุญแจ/เหรียญ/ช้อนส้อม** | เสียงกริ๊งแหลมกระจาย เด้งสูงกว่าที่คิด กระเด็นไกล ต้องก้มหาใต้โต๊ะ/ตู้ | กริ๊งสั้น เด้งน้อย | เงียบ จมลงพรม หาไม่เจอ (beat: มือคลำหา) |
| **หนังสือ/แฟ้มเอกสาร** | เสียง "พลั่ก" หนักแน่น กระดาษแทรกปลิวออกด้านข้าง สไลด์ต่ออีกนิด | เหมือนกัน | เสียงเบา |

**มรดก continuity:** เศษทุกชิ้น + ตำแหน่งการกระจาย (อ้าง absolute landmark) อยู่ต่อทุกช็อต
จนกว่าบทให้เก็บ ; ใครเดินผ่านบริเวณนั้น = ต้องเลี่ยง/เหยียบ (เหยียบ = เสียงกรอบ + beat ใหม่ฟรี).

## §2 ของเหลว (ชนิด × พฤติกรรม)

| ของเหลว | ตอนสาด (กลางอากาศ) | ตอนลงพื้น | คราบ/ไอ/มรดก |
|---------|--------------------|-----------|----------------|
| **น้ำเปล่า** | สายโค้งใสตามทิศเหวี่ยง แตกเป็นหยดปลายทาง | แผ่เร็ว แอ่งบางใส สะท้อนแสงไฟ | แห้งใน 2–3 ซีน พื้นลื่น (setup อุบัติเหตุต่อได้) |
| **กาแฟร้อน** | สายสีน้ำตาลเข้ม + **ไอลอยตามสาย** | แอ่งขยายช้า ตามร่องยาแนว **ไอลอยจากแอ่ง 1–2s แล้วจางหมด** | คราบน้ำตาลขอบแอ่ง ; **ช็อตถัดไปห้ามมีไอแล้ว** (เวลาเดินไปแล้ว) |
| **ไวน์แดง** | สายแดงเข้มหนืดกว่าน้ำ | แอ่งแดงเลือดนก กระเด็นเป็นจุดบนผนัง/ขากางเกง/ชายกระโปรง | คราบติดถาวรบนผ้า = ประจักษ์พยานทั้งเรื่อง (ใช้เล่าต่อได้ทั้ง EP) |
| **ซุป/ก๋วยเตี๋ยวร้อน** | ก้อนน้ำ+เส้น+ชิ้นเนื้อแยกวิถีกัน | ของแข็งกระจายเป็นกอง น้ำแผ่รอบ ไอพวยพุ่ง | เละ เก็บยาก คนต้องหยิบทีละชิ้น (beat ยาวได้) |
| **นม** | สายขาวทึบ เห็นชัดสุดบนพื้นเข้ม | แอ่งขาวขอบชัด | คราบ+กลิ่น (ตัวละครบ่นได้) |
| **เลือด (18+/horror)** | หนืด ไหลช้ากว่าน้ำ หยดเป็นเม็ดกลม | แอ่งขยายช้ามาก ขอบเข้ม | ⚠️ ใช้ตามเรตติ้งโปรเจกต์เท่านั้น |

**ฟิสิกส์แกน (ใส่เสมอ):** ของเหลวสาดไปทาง **โมเมนตัมเดิมของภาชนะ** ไม่ใช่รอบทิศ ·
หยดกระเซ็นเล็กไปไกลกว่าแอ่งหลัก (ถึงขาโต๊ะ/รองเท้า) · **หยดสุดท้ายหยดตามจากขอบโต๊ะ
ทีหลัง 1–2 หยด "แปะ...แปะ"** — detail เดียวที่ฆ่ากลิ่น AI ได้ทั้งช็อต.

## §3 คน: ล้ม/เซ/โดนแรง

| เหตุการณ์ | ลำดับฟิสิกส์จริง (เขียนตามลำดับนี้) |
|-----------|-------------------------------------|
| **สะดุด** | ปลายเท้าเกี่ยว → ตัวพุ่งไปหน้า → **มือยันพื้นก่อนเสมอ** (reflex) → ของในมือลอยต่อไปข้างหน้า → เข่าลงตาม → ค้างท่าคลาน 1 จังหวะ → ค่อยเช็คตัวเอง |
| **โดนตบ** | หัวสะบัดตามทิศแรง → เท้าเซถอยครึ่งก้าว → **มือแตะแก้มช้า ~0.5s หลังโดน** → ค่อยเงยหน้ากลับมา (ตรงนี้คือ acting beat) |
| **โดนผลัก** | เซถอย 1–2 ก้าว ส้นเท้าครูด → มือคว้าหาที่ยึด (ขอบโต๊ะ/พนัก) → ถ้าคว้าพลาด = ล้มก้น → ของบนโต๊ะที่ถูกคว้าสั่น/ตก (ลูกโซ่ต่อ §1) |
| **เข่าอ่อน/เป็นลม** | ทรุดแนวดิ่ง **เข่าพับก่อน** → ตัวพับด้านข้าง → ไม่ล้มทั้งแผ่นแบบหนัง ; คนรอบพุ่งเข้ารับช้ากว่าการล้มเสมอ (รับไม่ทัน = จริงกว่ารับทัน) |
| **ลุกพรวดจากโต๊ะ** | เก้าอี้ครูดพื้นเสียงยาว หรือล้มหงายดัง "โครม" → ขอบโต๊ะสั่น แก้ว/ช้อนสั่นกริ๊ก → **เก้าอี้ล้มต้องล้มต่อในช็อตถัดไป** |
| **วิ่งชนคน/ของ** | ทั้งคู่เด้งออกจากกัน (แรงสะท้อน) → ของในมือทั้งสองฝั่งหล่น (ลูกโซ่คูณสอง) → เสียง "อุ๊ย" หลุดก่อนคำพูดจริง |

## §4 Reflex timing มาตรฐานร่างกาย (ชั้น 4 — ใช้กับทุกเหตุการณ์)

| จังหวะ | เวลา | หมายเหตุ |
|--------|------|----------|
| สะดุ้ง/กะพริบตาหลังเสียงดัง | **~0.2s** | เกิดก่อนคิดเสมอ — ทุกคนในเฟรมโดนพร้อมกัน |
| สายตา track ของที่ตก | ทันที | คนมองตามของ **ไม่มองกล้อง** |
| มือที่ทำของหลุด "ค้างกลางอากาศ" | 0.5–1s | ท่าค้าง = signature ของ moment จริง |
| ยกเท้า/ถอยหนีน้ำกระเซ็น | 0.3–0.5s | ผู้หญิงใส่กระโปรง = ดึงชายกระโปรงหนีด้วย |
| มือแตะจุดที่โดน (ตบ/ชน) | ~0.5s หลังโดน | ช้ากว่าที่คิด — AI ชอบให้แตะทันที = ปลอม |
| **reaction อารมณ์** | **1–2s หลังเหตุการณ์** | มาช้ากว่า reflex เสมอ ; ระหว่างรอ = สีหน้าว่างเปล่า 1 จังหวะ (ทองคำ) |
| คนรอบหันมามอง | ไล่กัน 0.3–1s | **ไม่หันพร้อมกัน** (พร้อมกัน = หุ่นยนต์) ; ⛔ EXACTLY N คน กันโคลน |

## §5 อารมณ์ × reaction (เลือกชั้น 4 ตามซีน — จงใจ vs เผลอ ต้องแยกเสมอ)

| โหมด | ลักษณะ reaction |
|------|-----------------|
| **เผลอ/ตกใจ** | สะดุ้งเต็ม → มือปิดปาก → "ตาย!" หลุดปาก → ก้มเก็บทันที → มองคู่สนทนาขอโทษ |
| **โกรธ-จงใจ (ปัดทิ้ง)** | **ไม่มี startle เลย** (ตัวเองเป็นคนทำ) → **ไม่มองแก้วแม้แต่แวบเดียว** → จ้องอีกฝ่ายค้าง → มือที่ปัดค้างเหนือโต๊ะแล้วค่อยวางราบ → เศษแก้ว = ประจักษ์พยานความโกรธ ห้ามใครเก็บ |
| **เศร้า/ช็อกข่าวร้าย** | มือ "หมดแรง" — ของ **ลื่นหลุด** ไม่ใช่ปัด → ไม่ก้มเก็บ ไม่มองพื้น → มองเหม่อ/มองมือตัวเอง → คนอื่นในซีนเป็นฝ่ายก้มเก็บแทน |
| **กลัว/ผวา (horror)** | สะดุ้ง+ถอยเหยียบเศษ (เสียงกรอบ = beat ฟรี) → หลังชนผนัง/เฟอร์นิเจอร์ (ลูกโซ่ต่อ) |
| **แกล้งเผลอ (ตัวร้าย)** | ทำ startle "ช้าไปครึ่งจังหวะ" + มุมปากยิ้มก่อนขอโทษ — ให้คนดูจับได้ กล้องจับ CU มือ/ปาก |

## §GOLDEN — ตัวอย่างมาตรฐานทองคำ: "นางเอกปัดแก้วกาแฟตกลงพื้น"

> Input จาก user มีแค่นี้: **"นางเอกปัดแก้วกาแฟตกลงพื้น"**
> ระบบ audit: แก้วเซรามิกมีหู · กาแฟร้อนครึ่งแก้ว · ขอบโต๊ะ ~75cm · พื้นกระเบื้อง (จาก scene ref) ·
> ซีน = เผชิญหน้าสามี → **โหมดโกรธ-จงใจ** (§5). ตำแหน่ง/landmark ให้แทนตาม scene จริงของโปรเจกต์.

**PROMPT (บล็อก time-code — ต่อท้ายบล็อกตัวละคร/ฉาก/สไตล์/กล้องตามฟอร์แมต Loop ปกติ):**

- **0–5s:** นางเอกนั่งนิ่งที่โต๊ะกินข้าว [ฝั่ง landmark A] มือขวาวางข้างแก้วกาแฟเซรามิกขาว
  ที่ยังมีไอลอยจางๆ สายตาจ้องสามีที่นั่งตรงข้าม [ฝั่ง landmark B] ไม่กะพริบ สามีเปิดปากกำลังจะแก้ตัว
- **5–10s:** นางเอกปัดหลังมือครั้งเดียว สั้น เร็ว real-time — แก้วเหวี่ยงพ้นขอบโต๊ะ ลอยโค้งตาม
  ทิศปัด ~ครึ่งเมตร คว่ำกลางอากาศ กาแฟเริ่มสาดออกเป็นสายโค้งสีน้ำตาลตามโมเมนตัม →
  กระแทกกระเบื้อง: หูแก้วหักหลุด ตัวแก้วแตกเป็นชิ้นใหญ่ 3–4 ชิ้น สะเก็ดเล็กกระเด็นรัศมีสั้น
  เศษชิ้นใหญ่หมุนกริ๊งๆ ก่อนนิ่ง กาแฟสาดเป็นแนวยาวตามทิศเหวี่ยง หยดเล็กกระเซ็นถึงขาโต๊ะ
  แอ่งค่อยๆ ขยายตามร่องยาแนว ไอลอยจากแอ่งจางๆ — สามีสะดุ้งเต็มตัวตอนเสียงแตก (ก่อนคิด)
  เผลอมองพื้นตามเศษแก้ว
- **10–15s:** ความเงียบ. นางเอก **ไม่มองแก้วแม้แต่แวบเดียว** — สายตายังปักอยู่ที่สามี
  มือที่ปัดค้างเหนือโต๊ะหนึ่งจังหวะ แล้วค่อยๆ ลดลงวางราบกับโต๊ะ สามีเงยหน้าจากพื้น
  กลับมาเจอสายตาเธอ กลืนน้ำลาย หยดกาแฟหยดสุดท้ายไหลจากขอบโต๊ะลงแอ่ง "แปะ"
- **【音效】:** เสียงแก้วกระแทกกระเบื้อง "เพล้ง!" คมสั้นครั้งเดียว → เศษเซรามิกหมุนกริ๊งๆ
  สั้นๆ แล้วเงียบ → ความเงียบกดดัน มีแค่เสียงตู้เย็นหึ่งเบาๆ → หยดกาแฟจากขอบโต๊ะ "แปะ"
  1–2 หยด → ไม่มีดนตรี ไม่มีเสียงบรรยาย
- **⛔:** ทั้งคู่นั่งตำแหน่งเดิมตลอดช็อต ห้ามลุก ห้ามสลับฝั่ง (position lock ตามซีน) ·
  real-time speed ห้าม slow-motion ทุกจังหวะ · แก้วแตก **ครั้งเดียว** ห้ามรีเพลย์/ห้ามแก้วใบที่สอง ·
  เศษแก้วและแอ่งกาแฟห้ามหายกลางคลิป · EXACTLY 2 people, no extra people ·
  no split-screen · on-screen text = English only

**CONTINUITY NOTE → ช็อตถัดไปทุกช็อตในซีนนี้:**
เศษแก้วเซรามิกขาว 3–4 ชิ้น + สะเก็ด + แอ่งกาแฟแนวยาว อยู่บนพื้น [ข้าง landmark ที่แก้วตก]
— ต้องเห็นต่อเนื่องทุกช็อตจนกว่าบทให้เก็บ · **ไอกาแฟจางหมดแล้ว ช็อตถัดไปห้ามมีไอ** ·
มือขวานางเอกวางราบบนโต๊ะ · ใครเดินผ่านจุดนั้นต้องเลี่ยงหรือเหยียบ (เหยียบ = เสียงกรอบ).

### เทียบโหมดเผลอ-ตกใจ (input เดิม เปลี่ยนแค่บริบทอารมณ์)

5–10s ฟิสิกส์วัตถุ **เหมือนเดิมทุกอย่าง** (ลูกโซ่ชั้น 2–3 ไม่เปลี่ยนตามอารมณ์!) — เปลี่ยนเฉพาะชั้น 4:
มือปัดโดน "โดยไม่ตั้งใจ" ระหว่างเอื้อมหยิบของ → สะดุ้งเต็มตัว ~0.2s → สายตาพุ่งตามแก้วที่ลอย →
มือค้างกลางอากาศ 1 จังหวะ → "ตาย!" หลุดปาก → 10–15s ดึงชายกระโปรงหนีน้ำ ยกเท้าถอยครึ่งก้าว →
ก้มลงเก็บเศษชิ้นใหญ่ → เงยมองคู่สนทนาแบบขอโทษ. CONTINUITY NOTE เหมือนเดิม +
"เศษชิ้นใหญ่ 1 ชิ้นอยู่ในมือนางเอก".
