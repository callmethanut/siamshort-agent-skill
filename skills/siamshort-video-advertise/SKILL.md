# Advertise — brief in, finished commercial out

The platform's most reliable genre — BECAUSE prompts stay short and structured. Keep them that way.

## PHASE A — Story & pre-production

1. **Intake:** product (+ real product image refs) · ONE key message · tone (premium/fresh/tech) · presenter? + exact spoken line · length (15–30s) · ratio (16:9, 9:16 cut optional) · **gate mode**. Confirm.
2. **Write the ad story:** even 15 seconds has a story — hook (problem or desire) → product reveal → proof/feature beat → payoff + CTA moment. 3–6 beats, each one shot. **Approval gate on story + beat list.**
3. **Concept board:** 4-panel storyboard sheet (2×2, title block, ONE style sentence, consistency clause). Approval.
4. **Asset stills:** product hero via studio-isolation template (SINGLE object, seamless background, NO hands, purpose statement, material+finish words). Fine jewelry → macro, lock winner immediately. Presenter → canonical reference portrait.
5. **Cost gate** → explicit confirmation. Phase B runs to completion.

## PHASE B — Production loop (gen-loop engine over the beat list)

Per beat:
- b-roll beats: camera-first sentence → tactile adjectives → ONE action/eruption beat (slow-mo macro pattern) → one camera move · 5s
- presenter beat: identity ref + locked camera + "speaks naturally with synchronized lip movements. Says (<lang>): «exact line»"
- product-in-scene beats: hero still as ref, scoped ± (product only — not background/camera)
- generate → verify → inspect (premium feel? product accurate? message readable?) → repair by deviation table → accept → next beat
- loop until every beat on the board is DONE

## PHASE C — Assembly manifest
Ordered clips mapped to the story · CTA/logo note (brand text ALWAYS in post — never generated) · music direction · blocked-beat report.

## Non-negotiable
Story + board approval before generation · cost confirmation before Phase B · gen-loop discipline · no rendered brand text/logos · platform rules override.
