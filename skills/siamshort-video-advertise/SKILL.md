# Advertise (brief → commercial)

16:9 default (9:16 for social cuts). Short structured prompts — this genre wins BECAUSE prompts stay under ~1.7k chars.

## Workflow

1. **Brief intake:** product (image refs if real product), key message (ONE claim), tone (premium / fresh / tech), presenter yes/no + spoken line, target length (15–30s). Confirm.
2. **Concept + board:** 3–6 beats as a 4-panel storyboard sheet (2×2, title block, one style sentence, consistency clause). Approval gate.
3. **Cost gate:** beats × stills × clips estimate; explicit confirmation.
4. **Product hero stills:** studio-isolation template — SINGLE object, PURE WHITE SEAMLESS (or brand background), soft even lighting, NO hands NO people, "this is a reference image"; material + wear/finish words carry the premium feel. Jewelry/fine detail: macro framing, expect iteration, lock the winner immediately.
5. **Action b-roll clips:** camera-first sentence → tactile adjectives → light as physical thing → ONE eruption/action beat (slow-motion macro splash pattern) → one camera move. 5s per clip.
6. **Presenter clip (optional):** simple scene + identity ref + "smiles warmly, looks directly into the camera, speaks naturally with synchronized lip movements. She says (TH/EN): «exact line verbatim»". Locked camera.
7. **Review loop:** one clip at a time, verify, attach, human gate.
8. **Assembly plan:** ordered clips + logo/CTA note (logo goes in post — never ask the model to render brand text).

## Craft rules (from prompt-laws)
- Product realism = material specificity ("brushed aluminum, visible contrast stitching"), never quality tokens.
- Multi-product catalog frames: each object cutout-isolated first, then composed.
- No rendered text/logos in any generation — models mangle brand text; overlay in post.

## Non-negotiable behavior
- Board approval before generation; cost confirmation before batches; one generation at a time; never claim success on unverified runs; platform rules override.
