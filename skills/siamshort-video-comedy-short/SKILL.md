# Comedy Short — premise in, finished gag film out

Built on the platform's best-performing system (43.9%): SHOT cards + storyboard panels + long punchline holds. Comedy timing = HOLD shots, not montage.

## PHASE A — Story & pre-production

1. **Intake:** premise (one line) · cast size (≤3 named) · ONE location · length (30–60s) · style (photoreal / anime) · **gate mode**. Confirm.
2. **Write the comedy story:** full micro-script — setup (normal world) → escalation ×2 → the turn → punchline → tag. Every beat is one shot with an intent label ("HOLD SHOT — Punchline Landing") and a duration (setup 5s · punchline HOLDS 10–12s — the held reaction IS the laugh). Include the deadpan physical staging concretely. **Approval gate on the script.**
3. **Cast & location assets:** canonical reference portrait per character (single subject, purpose statement; photoreal → anti-plastic clause) · one DEPOPULATED location plate.
4. **Storyboards:** 4-panel sheets (2×2) per scene — title block, ONE style sentence, per-character identity mini-blocks, consistency clause, one beat per panel. Never >6 panels.
5. **Cost gate** → explicit confirmation. Phase B runs to completion.

## PHASE B — Production loop (gen-loop engine over the shot list)

Per shot — SHOT-card compose:
- `SHOT n: <TYPE> — <intent> (<time range>)` · CAST & LOCATION block · ACTION block (concrete physical staging; reflex beats for slapstick) · "follow storyboard panels x–y"
- long takes on punchline/reaction shots (10–12s, hold past comfort) · fast model variant is the proven route
- generate → verify → inspect (is the identity consistent? does the timing land? reactions readable?) → repair by deviation table (face drift → identity block + board ref; timing → time-blocks) → accept → next shot
- loop until the whole story's board is DONE

## PHASE C — Assembly manifest
Ordered shots · sound-gag notes for post · blocked-shot report.

## Non-negotiable
Script approval before generation · cost confirmation before Phase B · gen-loop discipline · one location per short · platform rules override.
