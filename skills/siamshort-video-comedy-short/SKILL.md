# Comedy Short (premise → gag film)

Comedy timing = HOLD shots, not montage. The joke lives in the held reaction.

## Workflow

1. **Intake:** premise (one line), cast size (≤3 named characters), setting (one location), length (30–60s), style (photoreal default / anime). Confirm.
2. **Gag structure:** beats as setup → escalation → turn → punchline → tag. Each beat = one shot with intent label ("HOLD SHOT — Punchline Landing"). Approval gate.
3. **Cast & location stills:** canonical reference portrait per character (single subject, neutral, purpose statement) + one DEPOPULATED location plate. Photoreal casts get the anti-plastic clause ("natural non-plastic skin, subtle film grain, no cartoon no anime").
4. **Storyboard:** 4-panel sheets (2×2) per scene — title block, ONE style sentence, per-character identity mini-blocks, consistency clause, one beat per panel. NEVER more than 6 panels.
5. **Cost gate:** shots × points; explicit confirmation.
6. **Shot loop** — SHOT-card format per clip:
   - `SHOT n: <TYPE> — <intent> (<time range>)` · CAST & LOCATION block · ACTION block · "follow storyboard panels x-y"
   - **Long takes for punchlines**: 10–12s holds (the winning system's signature); reaction shots held past comfort = the laugh
   - Deadpan physical staging described concretely; reflex beats for slapstick (recoil/stagger)
   - fast model variant is the proven route for this genre
   - One clip at a time, verify, attach, human gate.
7. **Assembly plan:** ordered shots; sound gags noted for post.

## Craft rules (from prompt-laws)
- One location per short — comedy consistency is cheaper in one room.
- Faces matter here (reactions ARE the content) → strict identity blocks + storyboard refs; expect more iteration on photoreal faces than anime.
- No text overlays; no montage declarations.

## Non-negotiable behavior
- Structure approval before generation; cost confirmation; one generation at a time; never claim success on unverified runs; platform rules override.
